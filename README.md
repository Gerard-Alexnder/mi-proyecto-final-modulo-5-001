Este Proyecto Utiliza modelos de Machine Learning para analizar la antiguedad de los clientes y el riesgo de abandono de una empresa de telecomunicaciones.

## Modelo de Regresion Lineal Multiple

El modelo de regersio busca predecir la antiguedad ('tenure') de un cliente a partir de su perfil y los servicios contratados, logrando un R2 de 0.65 y un MAE de aproximadamente 11.17 meses.

## Modelo de Clasificacion - Arbol de Decision

El Arbol de Decision busca identificar clientes con riesgo de abandono ('Churn') y obtuvo un Accuracy de 76.69%, recall de 63.37%, F1 de 59.10% y AUC de 0.833, mostrando ademas una buena generalizacion al limitar su profundidad a 4 niveles.
